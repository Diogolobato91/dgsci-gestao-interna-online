# DGSCI — Gestão e Apoio Operacional

Integração do sistema interno com o portal de apoio e o Arquivo DGSCI. Identidade laranja, preto e branco, navegação por setor, biblioteca React e consulta às planilhas com Mapbox.

## Executar

- `npm ci`
- `npm run dev`
- `npm test`
- `npm run typecheck`
- `npm run build`

A seleção de setor demonstra a navegação e não equivale a autenticação. A revisão deve ser hospedada privadamente. Contas, permissões reais e banco compartilhado são a próxima etapa. Não utilize credenciais do SISGAT nesta prévia.

Veja [o escopo e os limites desta integração](docs/INTEGRACAO_DGSCI.md) e [a origem do módulo Arquivo](public/arquivo/ORIGEM.md).
